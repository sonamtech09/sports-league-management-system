# Sports League Management System — PS 55

React + Vite academic project with Admin and User modules.

## Run locally
```bash
npm install
npm run dev
```

## Demo Admin
- Email: admin@slms.com
- Password: admin123

## Features
- User signup and login using browser Local Storage
- Admin and User role-based dashboards
- Team and player management
- Match fixture creation and result entry
- Automatically calculated league standings (3 points for a win, 1 for a draw)
- Activity log

## Deployment
Build with `npm run build`. Vercel framework preset: Vite; output directory: `dist`.

## Academic note
This is a front-end prototype. Local Storage is browser-specific and is not secure production authentication.

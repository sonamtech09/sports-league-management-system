## How to Run
No installation or backend is required.

1. Download/open the project folder.
2. Open `index.html` in a browser.
3. Login with the demo admin account:
   - Email: `admin@slms.com`
   - Password: `admin123`
4. Or open `signup.html` to create a normal User account.

## Important Academic Note
This is a front-end academic prototype. Local Storage is browser-specific and is not a replacement for a secure backend/database. The demo admin credentials are intentionally simple for project presentation.
